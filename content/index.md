## 🚀 Core Tech Stack

### 🟦 SAP Backend Evolution
- **ABAP Cloud & RAP (RESTful ABAP Programming Model)**: 최신 표준에 기반한 클라우드 최적화 백엔드 서비스를 구축합니다.
- **SAP BTP (Business Technology Platform)**: Side-by-Side 확장 개발 및 클라우드 환경에서의 서비스 연동을 다룹니다.
- **Classic ABAP (SD/MM/FI)**: 표준 프로세스에 대한 깊은 이해를 바탕으로 비즈니스 로직을 구현합니다.

### 🟧 Modern Frontend & Integration
- **SAP UI5 / Fiori**: 사용자 중심의 반응형 웹 어플리케이션을 개발합니다.
- **CAP (Cloud Application Programming Model)**: Node.js 기반의 유연한 클라우드 네이티브 서비스를 설계합니다.
- **Python**: Selenium 및 LangChain을 활용한 업무 자동화와 기술 실험을 병행합니다.
